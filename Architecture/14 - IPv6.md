# 14 — IPv6

Précédent : [13 - Subnetting, CIDR et VLSM](13%20-%20Subnetting%2C%20CIDR%20et%20VLSM.md) · Suivant : [15 - TCP, UDP et ports](15%20-%20TCP%2C%20UDP%20et%20ports.md)

## 1. Pourquoi IPv6 ?
- **Épuisement d'IPv4** (4,3 milliards d'adresses).
- IPv6 : **128 bits** → 2¹²⁸ adresses (≈ 3,4 × 10³⁸).
- Simplifie le routage, supprime le besoin de NAT, intègre le multicast (plus de broadcast), NDP et SLAAC.

## 2. Structure et écriture
128 bits = **8 groupes de 16 bits** en hexadécimal, séparés par `:`.
`2001:0db8:0000:0000:0000:0000:0000:0001`

**Règles de compression**
1. Supprimer les **zéros de tête** de chaque groupe : `2001:db8:0:0:0:0:0:1`.
2. Remplacer **une seule** suite de groupes nuls consécutifs par `::` : `2001:db8::1`.

Préfixe : `2001:db8:abcd:12::/64` → **/64** = taille standard d'un sous-réseau (64 bits réseau + 64 bits interface).
Structure typique : préfixe global /48 (site) + 16 bits (sous-réseau) + 64 bits (interface).

## 3. Types d'adresses
| Type | Préfixe | Rôle |
|---|---|---|
| **Global Unicast** | `2000::/3` | routable sur Internet (≈ IP publique) |
| **Link-local** | `fe80::/10` | valable **sur le lien uniquement**, obligatoire sur chaque interface |
| **Unique Local (ULA)** | `fc00::/7` (en pratique `fd00::/8`) | ≈ adresses privées |
| **Multicast** | `ff00::/8` | groupe (`ff02::1` tous les nœuds, `ff02::2` tous les routeurs) |
| **Loopback** | `::1/128` | machine locale |
| **Non spécifiée** | `::/128` | pas encore d'adresse |
| Documentation | `2001:db8::/32` | exemples |
| **Anycast** | (même format qu'unicast) | même adresse sur plusieurs nœuds, le plus proche répond |

Une interface possède **plusieurs adresses IPv6** en même temps (link-local + globale...). **Pas de broadcast.**

## 4. Attribution des adresses
- **Manuelle** (serveurs).
- **SLAAC** (Stateless Address Autoconfiguration) : le routeur annonce le préfixe par **Router Advertisement (RA)** ; l'hôte fabrique son adresse (identifiant aléatoire ou EUI-64).
- **DHCPv6** : attribution **stateful** (ou options DNS seules), ports UDP **546** (client) / **547** (serveur).

## 5. NDP (Neighbor Discovery Protocol)
Fonctionne au-dessus d'**ICMPv6** ; remplace ARP et plus :
| Message | Type ICMPv6 | Rôle |
|---|:-:|---|
| Router Solicitation (RS) | 133 | « y a-t-il un routeur ? » |
| Router Advertisement (RA) | 134 | annonce préfixe/passerelle |
| Neighbor Solicitation (NS) | 135 | équivalent ARP Request (multicast *solicited-node*) |
| Neighbor Advertisement (NA) | 136 | équivalent ARP Reply |

Détection d'adresses dupliquées (DAD) incluse. **Ne jamais bloquer ICMPv6 en totalité** : IPv6 cesserait de fonctionner.

## 6. Différences IPv4 / IPv6
| | IPv4 | IPv6 |
|---|---|---|
| Taille | 32 bits | 128 bits |
| Notation | décimale pointée | hexadécimale avec `:` |
| Broadcast | oui | **non** (multicast) |
| Résolution L2 | ARP | NDP |
| Configuration | manuelle / DHCP | manuelle / **SLAAC** / DHCPv6 |
| En-tête | variable (20–60 o) | **fixe 40 octets** |
| NAT | très utilisé | inutile en principe |
| Fragmentation | par les routeurs | **par la source uniquement** |
| IPsec | optionnel | pris en charge nativement |

Coexistence : **dual stack**, tunnels, NAT64.

## 7. Commandes
```bash
ip -6 addr           # Linux
ipconfig             # Windows
ping -6 ::1  |  ping6 2001:db8::1
ip -6 neigh          # voisins NDP
```

## 📌 À retenir
- 128 bits, 8 groupes hexa, `::` une seule fois.
- Link-local `fe80::/10`, global `2000::/3`, multicast `ff00::/8`.
- SLAAC + RA ; NDP remplace ARP ; pas de broadcast.

## 🧪 Exercices
1. Compresse `2001:0db8:0000:0000:0000:ff00:0042:8329`.
2. `fe80::1` est-elle routable sur Internet ?
3. Combien de bits pour l'identifiant d'hôte dans un /64 ?
