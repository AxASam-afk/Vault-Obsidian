# Les bases de données relationnelles

> [!info] Contexte du cours
> Principalement du **PostgreSQL** mais le plus connu est **MySQL** (racheté par Oracle) donc **MariaDB** représente la version open source. Il en existe plein d'autres : Oracle, SAP (HANA).

## Organisation du cours

- **15h** de cours : beaucoup de théorie + TP
- **Soutenance finale** + partiel papier SQL
- Focus sur les **requêtes SQL**

## Concepts clés

### Clés primaires / étrangères
- **Clé primaire (PK)** : identifiant unique d'une ligne dans une table
- **Clé étrangère (FK)** : référence vers une clé primaire d'une autre table
