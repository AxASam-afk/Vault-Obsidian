# Histoire de GitHub

> [!info] Définition **GitHub** est une plateforme web d'hébergement et de gestion de code source basée sur **Git**, le logiciel de contrôle de version distribué créé par **Linus Torvalds** en 2005 (pour les besoins du développement du noyau Linux). GitHub ajoute à Git des fonctionnalités collaboratives : pull requests, revue de code, gestion de tâches (issues), intégration continue, wikis, etc.

---

## Origines

- **19 octobre 2007** — début du développement de la plateforme
- **8 février 2008** — fondation officielle de l'entreprise, initialement sous le nom **Logical Awesome LLC**
- **Avril 2008** — lancement public de GitHub, après quelques mois de bêta
- **Fondateurs** : **Tom Preston-Werner**, **Chris Wanstrath**, **P.J. Hyett** et **Scott Chacon**
- Siège social : **San Francisco, Californie**

---

## Croissance

|Période|Événement|
|---|---|
|**2008**|Lancement de **GitHub Pages** et **GitHub Gist**|
|**Fin 2008**|Environ 33 000 dépôts créés en un an d'existence|
|**2014**|Levée de fonds de **250 millions de dollars** (Sequoia Capital, Andreessen Horowitz, Thrive Capital)|
|**2018**|Passage du cap des **100 millions de dépôts** hébergés|
|**2018**|Lancement de **GitHub Actions** (intégration/déploiement continu directement sur la plateforme)|
|**2023**|Plus de **100 millions de développeurs** et **420 millions de dépôts**, dont 28 millions publics|
|**2025**|Environ **150 millions d'utilisateurs** dans le monde|

---

## Le rachat par Microsoft (2018)

> [!important] Acquisition En **juin 2018**, **Microsoft** annonce le rachat de GitHub pour **7,5 milliards de dollars**. L'opération est officialisée par **Satya Nadella**, CEO de Microsoft.

### Contexte

- Microsoft venait déjà de racheter LinkedIn en 2016 pour 26 milliards de dollars
- L'annonce inquiète une partie de la communauté open source, Microsoft ayant longtemps été perçue comme hostile aux logiciels libres dans les années 2000 (l'ancien CEO Steve Ballmer avait notamment qualifié Linux de _« cancer »_)
- Malgré les craintes, GitHub continue de fonctionner de façon largement indépendante après le rachat, et poursuit sa croissance

---

## GitHub aujourd'hui

- **Filiale de Microsoft** depuis 2018, mais conserve sa marque et son fonctionnement propre
- Plus grand hébergeur de code source open source au monde
- Fonctionnalités majeures actuelles :
    - **GitHub Actions** (CI/CD)
    - **GitHub Copilot** (assistant de code basé sur l'IA)
    - **GitHub Packages**, **GitHub Codespaces**
- Héberge des projets majeurs comme _Visual Studio Code_, _TensorFlow_, _Kubernetes_, _React Native_

## Différence Git / GitHub

||Git|GitHub|
|---|---|---|
|**Nature**|Logiciel de contrôle de version distribué|Plateforme web construite autour de Git|
|**Fonctionnement**|Local, en ligne de commande|Hébergement en ligne + interface graphique|
|**Créé par**|Linus Torvalds (2005)|Tom Preston-Werner, Chris Wanstrath, P.J. Hyett, Scott Chacon (2008)|
|**Rôle**|Gérer l'historique des versions d'un code|Collaborer, partager, discuter et héberger ce code|
