## 🧠 Notions clés à retenir
- Mobile-first : une classe sans breakpoint s'applique à **toutes** les tailles, un breakpoint s'applique **à partir de** cette taille.
- Bootstrap = **classes utilitaires** + **composants** + **grille 12 colonnes**.
- Nommage : `propriété-breakpoint-valeur` → ex. `d-md-none`, `col-lg-4`, `mt-3`.
