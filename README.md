# Vault Obsidian - 1ère Année Informatique

Ce dépôt contient mon vault Obsidian personnel pour ma **1ère année d'informatique** à l'ESGI.

## Contenu

Ce vault regroupe l'ensemble de mes cours organisés par matière :

- **Algo** — Algorithmique et structures de données
- **Anglais** — Anglais technique et professionnel
- **Architecture** — Architecture des ordinateurs / systèmes
- **GitHub** — Utilisation de Git, GitHub, workflows
- **IMAGES** — Ressources visuelles, schémas, captures d'écran
- **Language C** — Programmation en langage C
- **Liens** — Ressources externes, documentation, liens utiles
- **Modélisation** — Modélisation de données, UML, Merise
- **OSINT** — Open Source Intelligence, veille technologique
- **Professionnel** — Compétences transverses, soft skills, projet pro
- **Réseaux** — Réseaux informatiques, protocoles, administration
- **UX** — Expérience utilisateur, design d'interface
- **VBA** — Visual Basic for Applications, automatisation Excel

## Utilisation

1. Cloner ce dépôt
2. L'ouvrir comme vault dans Obsidian (`Ouvrir un dossier comme vault`)
3. Le fichier `INDEX.md` sert de point d'entrée pour naviguer entre les cours
