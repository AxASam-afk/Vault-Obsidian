## Grammaire B1 - Points Cles

| Notion | Structure | Usage | Exemple |
|--------|-----------|-------|---------|
| **Pres Perfect vs Past S** | have/has + V3 vs V2 | Experience vs Moment precise | *I've seen it* vs *I saw it yesterday* |
| **Conditionnel 2** | If + past, would + V | Hypothese presente/future | *If I won, I'd travel* |
| **Conditionnel 3** | If + past perfect, would have + V3 | Regret passe | *If I'd known, I'd have come* |
| **Modaux deduction passe** | must/could/might have + V3 | Deduction sur passe | *He must have forgotten* |
| **Gerondif vs Infinitif** | verb + -ing / to + verb | Selon le verbe precedent | *enjoy doing* / *decide to do* |
| **Passive (tous temps)** | be (tense) + V3 | Focus objet | *It is being repaired* |
| **Reported Speech avance** | tense backshift + modaux | Rapporter questions/ordres | *He asked if I knew* |
| **Relatives** | who/which/that/whose/where | Definir/ajouter info | *The man who called* |
| **Connecteurs** | however/therefore/although | Cohesion texte | *However, it was expensive* |
| **Phrasal Verbs** | verb + particule | Verbes a particules | *give up, look forward to* |
| **Wish/If only** | wish + past / past perfect | Regret present/passe | *I wish I knew / I wish I'd known* |
