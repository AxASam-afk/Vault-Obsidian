## Grammaire A2 - Points Cles

| Notion | Forme | Usage | Exemple |
|--------|-------|-------|---------|
| **Past Simple** | V-ed / V2 | Action terminee passee | *I visited Paris last year* |
| **Present Perfect** | have/has + V3 | Experience vie / resultat present | *I have visited Paris* |
| **Present Perfect Cont.** | have/has been + -ing | Duree depuis le passe | *I have been learning English for 2 years* |
| **Will vs Going to** | will / be going to | Prediction / Intention | *It will rain* / *I'm going to study* |
| **Comparatifs** | -er / more + adj | Comparer 2 elements | *bigger / more interesting* |
| **Superlatifs** | -est / most + adj | Le plus dans un groupe | *the biggest / the most interesting* |
| **Must vs Have to** | must / have to | Obligation interne / externe | *I must study* / *I have to wear a uniform* |
| **Should** | should + V | Conseil | *You should see a doctor* |
| **Modaux probabilite** | might/could/must/can't be | Deduction | *He must be tired* |
| **Conditionnel 1** | If + present, will + V | Reel possible futur | *If it rains, I'll stay home* |
| **Passive simple** | be + V3 | Focus sur l'objet | *The book was written by...* |
| **Reported Speech** | say/tell + tense backshift | Rapporter paroles | *He said he was tired* |
