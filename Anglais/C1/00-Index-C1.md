## Grammaire C1 - Points Experts

| Notion | Description | Exemple |
|--------|-------------|---------|
| **Aspect perfectif/imperfectif** | Nuances aspectuelles fines | *I've been reading* (process) vs *I've read* (completion) |
| **Modalite epistemique** | Degré de certitude/evidence | *He must be tired* (certitude) vs *He might be tired* (possibilite) |
| **Embedding multiple** | Subordination centre/echelonnee | *The fact that he said that he thought that...* |
| **Stance markers** | Positionnement enonciateur | *Frankly speaking, it seems to me that...* |
| **Metaphore conceptuelle** | SYSTEMATICITE metaphores | *ARGUMENT IS WAR* (defend, attack, shoot down) |
| **Implicature conversationnelle** | Sens non-dit (Grice) | *It's cold in here* => *Close the window* |
| **Chaines lexciales** | Cohesion par repetition/synonymie | *pollution -> emissions -> contaminants -> toxins* |
| **Get-passive** | Adversatif/involontaire | *He got fired* (malheur) vs *He was fired* (neutre) |
| **Portee negation** | Ambiguite portee | *All that glitters is not gold* (pas tout) vs *Not all that...* |
| **Focus informationnel** | Theme/Rheme, given/new | *What matters is the result* (wh-cleft focus) |

## Objectifs Validation C1 (CEFR)

- [ ] Comprendre textes longs, complexes, implicites (litteraires, specialises)
- [ ] S'exprimer spontanement, couramment, sans recherche de mots
- [ ] Utiliser langue de facon flexible, effective (social, pro, academique)
- [ ] Produire textes clairs, bien structures, sujets complexes
- [ ] Maitriser connecteurs, articulation, cohesion
- [ ] ~8000-10000 mots actifs
