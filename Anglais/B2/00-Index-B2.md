## Grammaire B2 - Points Cles

| Notion | Structure | Usage | Exemple |
|--------|-----------|-------|---------|
| **Conditionnels mixtes** | If + past perf, would + V | Passe -> Present | *If I'd studied, I'd be a doctor* |
| **Inversion** | Aux + Suj + V (apres neg) | Emphase, formel | *Never have I seen such beauty* |
| **Subjonctif formel** | that + bare infinitive | Apres suggest/insist/demand | *I insist that he leave* |
| **Cleft sentences** | It is X who/that... / What... | Focus information | *It was the cost that prevented me* |
| **Nominalisation** | Verbe/Adj -> Nom | Style academique | *The analysis of the data* |
| **Hedging** | tend to, appear to, suggest | Prudence academique | *The results suggest that...* |
| **Participles clauses** | -ing / -ed / having + V3 | Concision, style ecrit | *Having finished, he left* |
| **Reporting verbs** | verb + that/-ing/to/inf | Variete rapport | *He denied taking it / He admitted it* |
| **Relatives reduites** | who/which + be -> -ing/-ed | Concision | *The book written by... / The man standing...* |
